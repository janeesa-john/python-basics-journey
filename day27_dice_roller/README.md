# Dice Roller 🎲

A simple Python CLI project that simulates rolling a dice.

---

## 🚀 Features

* Roll a dice and get a random number from 1 to 6
* Roll multiple times
* User-friendly CLI interaction
* Input validation
* Tracks total number of rolls 
* Stores roll history 
* Improved input handling

---

## 🛠️ Tech Used

* Python
* `random` module
* Loops
* Conditional statements

---

## ▶️ How to Run

```bash
python main.py
```

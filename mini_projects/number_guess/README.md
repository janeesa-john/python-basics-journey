# Number Guessing Game 🎯

A simple command-line game where the user tries to guess a randomly generated number within a limited number of attempts.

---

## 🚀 Features

* Random number generation (1–100)
* User input-based guessing
* Feedback for each guess (Too high / Too low)
* Limited number of attempts
* Win/Lose outcome

---

## 🛠️ Tech Stack

* Python

---

## ▶️ How to Run

```bash
python game.py
```

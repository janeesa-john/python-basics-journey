# Expense Tracker 💸

A command-line Expense Tracker built using Python.

This project allows users to record daily expenses, view all entries, and calculate the total amount spent through a simple menu-driven interface.

---

## 🚀 Features

* Add new expenses
* View all saved expenses
* Show total amount spent
* Simple and user-friendly CLI menu
* Loop-based interactive program

---

## 🛠️ Tech Stack

* Python
* Functions
* Lists
* Dictionaries
* Loops
* Conditional Statements

# Contact Book 📒

A command-line Contact Book application built using Python.
This project allows users to store and manage contacts through a simple menu-driven interface.

---

## 🚀 Features

* Add new contacts
* View all saved contacts
* Search contact by name
* Delete contact by name
* Exit application safely

---

## 🛠️ Tech Stack

* Python
* Dictionary Data Structure
* Conditional Statements
* Loops

---

## 📂 Project Structure

* `main.py` – Main application logic

---

## ▶️ How to Run

```bash
python main.py
```

---

## 💡 Example Menu

```text
1. Add Contact
2. View Contacts
3. Search Contact
4. Delete Contact
5. Exit
```

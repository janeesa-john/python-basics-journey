# CLI To-Do Application 📝

A simple command-line based To-Do application built using Python.
This project helps users manage their daily tasks efficiently through a terminal interface.

---

## 🚀 Features

* Add new tasks
* View all tasks
* Delete tasks by selecting task number
* Persistent storage using file handling

---

## 🛠️ Tech Stack

* Python
* File Handling

---

## 📂 Project Structure

* `main.py` – Core application logic
* `tasks.txt` – Stores tasks permanently

---

## ▶️ How to Run

1. Open terminal in project folder
2. Run:

```
python main.py
```

---

## 💡 Example Usage

```
1. Add Task
2. View Tasks
3. Delete Task
4. Exit
```

# Food Order System 🍽️

A simple CLI-based Python application built to practice Python function arguments through a real-world food ordering scenario.

---

## 🚀 Features

* Add customer orders
* Accept multiple food items
* Store customer details
* Calculate delivery charge
* Generate total bill amount
* Display complete order summary

---

## 🛠️ Tech Used

* Python
* Functions
* Required Arguments
* Default Arguments
* `*args`
* `**kwargs`

---

## 📂 Files

* `main.py` – Main application logic

---

## ▶️ How to Run

```bash id="m3k9qv"
python main.py
```
